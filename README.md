# 角色换肤库

SillyTavern 前端扩展。提供甲/乙槽位、作品分组、角色搜索、作品内随机、服装分组和输入框自动填充。

## v1.4.3 型月与终末地补充

- 当前共 401 个角色、22 个分类，本次新增 37 个角色。
- “Fate系列”扩展为“型月系列”，从 20 人补充至 45 人，包含 Fate／FGO、月姬、空之境界和魔法使之夜；每位角色保留原作品标注，支持按原作品搜索。
- 新增独立的“明日方舟：终末地”分类，共 12 人。

## v1.4.2 角色名单调整

- 该版本共 364 个角色、21 个分类；按个人选择删去 240 个原有角色，新增 70 个角色。
- 星穹铁道由 20 人补充至 52 人；新增尘白禁区、战双帕弥什、死或生。
- 尼尔的三个分类合并为“尼尔系列”，共 7 人。
- 最终幻想7、生化危机与本次新增的单独人物合并到“其他角色”，共 13 人。角色卡片仍显示原作品名，也可以按原作品名搜索。
- 作品分类显示人数，搜索同时支持角色名、英文 tag、分类和原作品名。
- 服装库仍为 148 项。

已安装的用户可在酒馆扩展管理中更新“角色换肤库”，然后刷新页面。版本号应显示为 1.4.3。

角色与服装数据仍以加密文件保存，仓库不直接提供明文数据。扩展内置自动读取能力，因此不再要求输入密码；这只能避免直接查看明文，不能作为真正的访问权限保护。

## 安装

在 SillyTavern 中打开“扩展 → 安装扩展程序”，粘贴本仓库地址；也可以将整个文件夹复制到以下任一位置：

- 当前用户：`SillyTavern/data/<你的用户>/extensions/role-outfit-library`
- 所有用户：`SillyTavern/public/scripts/extensions/third-party/role-outfit-library`

重启 SillyTavern 或刷新页面。聊天输入区的衣服图标可以直接打开换肤库；手机上还会显示右下角常驻“衣”按钮。点一下打开，再点一下“×”关闭。手机选择器使用紧凑底部面板，作品与服装分类使用下拉框，角色卡片适配触控；内容较少时面板会自然收起，内容较多时仅列表滚动。切换聊天或界面重绘后，入口会自动恢复。也可以在扩展设置面板中展开“角色换肤库”。

## 操作

1. 选择甲或乙槽。
2. 在“角色”页点击作品，再点击角色；也可搜索或作品内随机。
3. 在“服装”页点击分类，再点击具体服装；也可分类内随机。
4. 每次选择后都会写入 `role_a / role_b / outfit_a / outfit_b`，并把原规则文本放进酒馆输入框，但不会自动发送。

角色的中文名和中文作品名只在扩展界面中显示，写入聊天框的是角色本身的 NAI 英文 tag。例如胡桃为 `hu tao (genshin impact)`，蒂法则为 `tifa lockhart`；不会给每个角色强行添加作品后缀。服装输出格式为 `【中文服装名】英文服装 tags`，两类内容分别写入对应槽位。
